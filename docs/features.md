# Что люди автоматизируют в MAX

Каталог сценариев, собранный из существующих проектов под MAX и из
плагинов-аналогов в Telegram. Данные на 2026-07-29. Обзор конкурентов и цифры
по рынку — в [research.md](research.md), здесь только сценарии.

## Сценарии, подтверждённые реальными проектами под MAX

Отсортировано по частоте появления в чужих репозиториях.

### 1. Мост в Telegram — самый массовый сценарий

`timka-123/max-resend`, `eiler2005/maxgram`, `Sharkow1743/SferumTransferBot`,
`IVANIVANOV-root/tg-max-relay`.

Причина спроса: MAX обязателен в школах и госучреждениях, а ставить ещё один
клиент люди не хотят. `maxgram` зеркалит каждый чат MAX в тему
Telegram-супергруппы и маршрутизирует ответы обратно — то есть даёт полноценную
работу с MAX без установки MAX.

Технически это: подписка на события → фильтрация по чатам → пересылка с
сохранением автора и вложений → обратный канал.

### 2. Пересылка уведомлений в сторонние каналы

`ilcommm/Max2iMessage` — macOS-приложение, пересылает уведомления MAX в iMessage
и на почту. Оттуда же две важные детали: несколько аккаунтов MAX, у каждого свой
получатель, и защита от дублей через персистентное хранилище.

### 3. Автоответчик и AI-секретарь

Разбор на Habr (статья 1037182) — юзербот отвечает от имени владельца, контакт
в адресной книге выглядит как обычный человек. У самого MAX есть встроенный
автоответчик, но он примитивен: одно сообщение по факту отсутствия в сети, без
условий и контекста.

### 4. Выгрузка и парсинг истории

Habr 1022316 (8.8k просмотров): выгрузка переписки из группы или диалога,
фильтрация по дате. Для сравнения — коммерческий шлюз Green-API отдаёт максимум
5000 сообщений за 3 месяца; у прямого доступа к внутреннему API такого потолка
нет.

### 5. Команды в собственных чатах

Пример из `vkmax`: юзербот слушает свои же сообщения, ловит префикс `.weather` /
`.info` и **редактирует своё сообщение**, подставляя результат. Классический
приём юзерботов — не засорять чат, а переписывать собственную реплику.

### 6. Администрирование групп

Покрыто и `PyMax`, и `go-max-client`: создание групп, участники, права,
инвайт-ссылки, настройки, закрепы, назначение админов.

### 7. Скачивание медиа

Фото, видео, документы, голосовые — есть во всех транспортных библиотеках.

### 8. Рассылки — сознательно за периметром

Существует коммерческий MAX Sender, чья реклама прямо построена на том, «что
банит аккаунты». Это подтверждает и спрос, и риск. В наш проект функция не
входит — см. правовой раздел в [../CLAUDE.md](../CLAUDE.md).

## Что даёт транспортный слой (потолок возможностей)

Объединённый список возможностей `PyMax`, `go-max-client` и
`unosmm/max-messenger-mobile-api-unofficial` — это фактический потолок того, что
вообще можно автоматизировать:

- Авторизация по телефону и SMS, QR-авторизация веб-клиента, вход по токену.
- Сообщения: отправка, ответ, reply, редактирование, удаление, реакции, закреп,
  отметка о прочтении, история.
- Чаты, группы, каналы, участники, инвайт-ссылки, настройки групп.
- Пользователи, контакты, профиль, папки, активные сессии, 2FA.
- Вложения: фото, файлы, видео, голосовые.
- Статусы и сторис (в мобильном SDK).
- Звонки: инициирование, приём, поток данных через ICE (в `go-max-client`).
- Реконнект с экспоненциальным backoff, keepalive, sync-state.

## Сценарии из Telegram, переносимые на MAX

Из 80+ плагинов `TeamUltroid/Ultroid` на юзербот-модель MAX ложатся:

| Плагин | Что делает | Приоритет для нас |
|---|---|---|
| `schedulemsg` | отложенная и повторяющаяся отправка | высокий |
| `pmpermit` | фильтр входящих личных сообщений от незнакомых | высокий |
| `afk` | автоответ «отошёл» с учётом контекста | высокий |
| `notes`, `snips` | заготовки текстов по короткой команде | высокий |
| `downloadupload`, `mediatools` | скачивание и обработка медиа | средний |
| `filter`, `blacklist`, `antiflood` | реакция на ключевые слова, антифлуд | средний |
| `chatbot` (`aiwrapper`) | подключение LLM как автоответчика | средний |
| `admintools`, `mute`, `warn`, `locks` | администрирование чатов | средний |
| `greetings` | приветствие новых участников | низкий |
| `stories` | работа со сторис | низкий |
| `broadcast`, `delayspam`, `autoban` | массовые действия | **не делаем** |

## Вывод для продукта

Первая версия закрывает то, что подтверждено спросом и не требует массовых
действий: **пересылка/мост, автоответчик, планировщик, выгрузка истории,
мультиаккаунт**. Всё остальное — плагинами поверх ядра.
