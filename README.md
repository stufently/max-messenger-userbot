# MAX Userbot — автоматизация пользовательских аккаунтов в мессенджере МАКС (max.ru)

Юзербот для мессенджера MAX: платформа автоматизации действий от имени обычного
пользовательского аккаунта — мультиаккаунт, пересылка сообщений, планировщик,
плагины.

> **Статус: проектирование.** Кода пока нет, идёт проработка архитектуры.
> Ландшафт ниши и обоснование решений — в [docs/research.md](docs/research.md),
> текущие задачи — в [TASKS.md](TASKS.md).

## Чем юзербот отличается от бота в MAX

| | Бот (Bot API) | Юзербот (этот проект) |
|---|---|---|
| От чьего имени работает | отдельный аккаунт-бот | ваш обычный аккаунт |
| API | официальный `platform-api.max.ru` | внутренний API мессенджера |
| Кто может опубликовать | только верифицированные юрлица, ИП и самозанятые — резиденты РФ | ограничений на публикацию нет |
| Видит переписку в обычных чатах | нет | да |
| Поддержка со стороны MAX | официальная | отсутствует |

Коротко: бот — это отдельный участник чата, которого нужно куда-то пригласить.
Юзербот работает как вы сами и видит ровно то, что видите вы.

## Что планируется

- **Мультиаккаунт** — пул аккаунтов под одним процессом, изолированные сессии.
- **Пересылка (форвардинг)** — правила «из чата А в чат Б» с фильтрами и
  преобразованием текста, живая синхронизация.
- **Планировщик** — отложенные и повторяющиеся отправки.
- **Плагины** — модульное ядро, свои сценарии без правки самого ядра.
- **Хранение сессий** — безопасное хранение и ротация авторизационных данных.
- **CLI** — управление из терминала, запуск в Docker.

## Установка

Пока нечего устанавливать. Планируемые артефакты: пакет `max-userbot` на PyPI и
Docker-образ; команда CLI — `maxub`.

## FAQ

**Что такое юзербот для MAX?**
Программа, которая подключается к мессенджеру MAX под вашим обычным аккаунтом и
выполняет действия за вас: отвечает, пересылает, собирает сообщения, работает по
расписанию.

**Чем юзербот отличается от чат-бота MAX?**
Бот требует верификации юрлица и работает как отдельный участник чата. Юзербот
действует от вашего имени и не требует регистрации в MAX. Подробности — в
таблице выше.

**Можно ли вести несколько аккаунтов MAX одновременно?**
Да, мультиаккаунт — одна из ключевых задач проекта.

**Как получить сессию MAX?**
Через авторизацию по номеру телефона, как в обычном клиенте. Сессия сохраняется
локально и переиспользуется при следующих запусках.

**Нужен ли для юзербота официальный MAX Bot API?**
Нет. Bot API покрывает только ботов и не даёт доступа к пользовательскому
аккаунту.

**Существуют ли готовые библиотеки для MAX?**
Да, несколько низкоуровневых обёрток внутреннего API — их обзор в
[docs/research.md](docs/research.md).

## Дисклеймер

Проект не является официальным продуктом MAX и не связан с VK. Он опирается на
внутренний (не документированный) API мессенджера, полученный методом обратной
разработки. Из этого следует:

- Использование юзербота **противоречит пользовательскому соглашению MAX**.
  Аккаунт может быть заблокирован.
- Внутренний API меняется без предупреждения — работоспособность не
  гарантируется.
- Массовые действия (рассылки, добавление в чаты, сбор данных) с пользовательских
  аккаунтов — прямой путь к блокировке и, в зависимости от сценария, к нарушению
  законодательства о персональных данных.

Используйте на свой страх и риск, для личной автоматизации собственных аккаунтов.
